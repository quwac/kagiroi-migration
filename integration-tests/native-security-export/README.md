# Native security exporter contract

This standalone composite build uses a Kagiroi source checkout containing the
native security APIs and this Kagiroi Migration checkout. Its schema roots are
ordinary `Table` definitions with `postgresRls`, `sqlServerRls`, and `oracleVpd`
registered in `init` blocks.

From the Kagiroi Migration repository root, run:

```sh
node integration-tests/native-security-export/test-export.mjs /absolute/path/to/kagiroi
```

The contract runs the real generated Kotlin/JS schema exporter, reads canonical
format version 2, generates one executable migration per dialect, verifies each
artifact chain, and confirms that a repeated generation reports no changes.
The SQL Server schema includes contributions from two tables to one policy.

The test clears only each fixture project's `build/contract-migrations` directory.
It does not connect to a database. Predicate functions and trusted context setters
are stable references; they are not generated by this fixture.
